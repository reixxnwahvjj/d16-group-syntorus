## Overview

D16 Group Syntorus emulates the lush double-engine chorus circuits found in classic 1980s synthesizers, delivering the warm, swirling modulation that defined the era's signature pads.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **D16 Group Syntorus** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dual Engine** | Two independent chorus engines running in series or parallel |
| **Analog Model** | BBD bucket-brigade delay circuit modeled for authentic vintage tone |
| **Stereo Output** | Wide stereo image with independent left/right modulation phase |
| **Sync Mode** | Lock modulation speed to host BPM for rhythmic chorus effects |
